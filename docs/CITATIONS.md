# Dataset and software citations

Cite the exact data product documentation and version used in an analysis. Do not cite a general NASA landing page as proof that a particular granule was downloaded.

## Data sources planned for evaluation

- **MODIS vegetation index:** MODIS/Terra Vegetation Indices Monthly L3 Global 1 km, commonly identified as MOD13A3. Confirm the collection/version and product metadata for the actual files used.
- **GPM precipitation:** GPM IMERG monthly precipitation product, commonly identified as GPM_3IMERGM. Confirm the product version, units, and temporal coverage for the actual files used.

## Required citation record

For each dataset, preserve the provider's recommended citation, product short name, collection/version, DOI or stable landing page when available, access date, and identifiers of the downloaded granules.

Also cite the software or methods used for correlation, uncertainty estimation, and multiple-testing correction where appropriate.

The product names above describe intended sources only. They do not establish that data have been acquired or processed in this repository. Fill in final citations from the metadata for the actual data release.

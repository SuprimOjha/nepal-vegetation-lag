# Research glossary

- **NDVI** — Normalized Difference Vegetation Index, a remote-sensing indicator related to green vegetation.
- **Precipitation anomaly** — Difference between observed precipitation and a defined baseline expectation.
- **Vegetation anomaly** — Difference between an NDVI observation and its defined baseline expectation.
- **Response lag** — Time offset at which a specified association between rainfall and vegetation is strongest under the chosen method.
- **Lag convention** — The explicit rule defining whether a positive lag means vegetation follows rainfall or the reverse. It must be stated in outputs.
- **Quality mask** — A rule that excludes observations flagged as unreliable by the data provider or processing workflow.
- **Effective sample size** — An estimate of independent information after accounting for temporal dependence.
- **p-value** — A statistic used to assess compatibility with a specified null model; it is not the probability that a hypothesis is true.
- **FDR** — False discovery rate, the expected proportion of false discoveries among rejected hypotheses under the method's assumptions.
- **Regridding** — Mapping spatial data from one grid to another using a documented method.
- **Granule** — A provider-defined unit of an Earth-observation product.
- **Provenance** — Metadata that records where data came from and how they were transformed.
- **Not computed** — No analysis result has been produced; this must not be confused with a measured zero.
